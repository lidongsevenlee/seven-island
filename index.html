常见问题

需要什么系统？

Seven Island 支持 macOS 14 Sonoma 及以上系统。实时频谱需要 macOS 14.2 及以上系统。

怎样安装和展开？

下载 DMG，打开后将 Seven Island 拖入「应用程序」。启动应用后，把鼠标移到屏幕顶部中央即可展开。

音乐频谱和歌词需要什么权限？

实时频谱使用 macOS 的系统音频录制权限。可在 Seven Island 的「设置 → 媒体」中授权读取 Apple Music 歌词缓存。歌词同步取决于可用数据。

剪贴板和备忘录存在哪里？

剪贴板历史和备忘录保存在当前 Mac 上。

演示对应哪个版本？

演示录自当前开发版。已发布版本的功能详见 GitHub 发布记录。
