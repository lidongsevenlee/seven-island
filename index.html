把常用工具放进 Mac 刘海

把鼠标移到屏幕顶部，控制音乐、找回剪贴板内容、打开项目，或随手记下想法。

下载 macOS 版 ↓ 看使用演示 ↘

适用于 macOS 14 及以上

从听歌
到继续工作

收起时，播放状态留在刘海。展开后，用四个标签切换手边的工具。

♪

音乐

控制播放和进度，查看实时频谱。有同步时间的歌词会跟着播放位置走。

▤

剪贴板

找回复制过的文字和图片。再次复制同一内容时，条目会回到列表顶部。

›_

VS Code 项目

搜索工作目录和固定项目，点击即可在 VS Code 中打开。

≡

备忘录

同时保留多份备忘录，点击标签切换，文字自动保存在本机。

刘海还可以显示日历，以及音量和亮度调节提示。

安装 Seven Island

下载 DMG，打开后将 Seven Island 拖入「应用程序」。

版本说明

演示展示当前开发版。GitHub Releases 提供已发布版本和更新说明。

音频和歌词

实时频谱需要系统音频录制权限。Apple Music 缓存歌词可在「设置 → 媒体」中授权读取。
