macOS 刘海控制中心

Mac 刘海里的常用工具

控制音乐、找回复制过的内容、打开项目、记下想法。
把鼠标移到屏幕顶部，随时展开。

下载 macOS 版 ↓ 查看实际界面 ↘

适用于 macOS 14 及以上

功能

从听歌到继续工作

收起时显示播放状态，展开后切换到你手头需要的工具。

♫

音乐跟着播放走

在刘海控制播放和进度。实时频谱随声音变化，有同步时间的歌词会跟随播放位置。

▤

找回复制过的内容

搜索剪贴板历史。再次复制的内容会回到列表顶部。

›_

打开 VS Code 项目

按名称搜索工作目录和固定项目，点击即可打开。

≡

随手记下想法

新建多个备忘录，横向标签一键切换，文字自动保存。

还有日历和 HUD查看日程，音量和亮度调节也能在刘海里显示。

安装 Seven Island

从 GitHub Releases 下载 DMG，打开后将应用拖入「应用程序」。

系统要求

macOS 14 Sonoma 或更高版本。

版本说明

页面展示当前开发版。GitHub Releases 提供已发布版本和更新说明。

音频和歌词

实时频谱需要系统音频录制权限。Apple Music 缓存歌词可在「设置」的「媒体」中授权读取。
